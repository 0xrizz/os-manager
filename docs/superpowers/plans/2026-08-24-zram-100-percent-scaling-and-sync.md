# zRAM 100% (8GB) Scaling & Subsystem Synchronization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scale zRAM compressed memory capacity from 50% (~3.75 GiB) to 100% of RAM (~7.5 GiB / 8192 MB) on the live Debian 13 host, synchronize configuration templates across `os-manager` codebase (`os_manager/commands/hsi.py`, `scripts/hsi-harden.sh`, tests), and verify live systemd, EarlyOOM, and `osm` CLI telemetry.

**Architecture:** Update `systemd-zram-generator` configuration to `zram-size = min(ram, 8192)` with multi-stream `zstd` compression and priority 100. Apply non-disruptive live swap recycling (`swapoff` -> `systemctl daemon-reload` -> `systemctl restart systemd-zram-setup@zram0.service` -> `swapon`), refresh EarlyOOM daemon threshold margins, update codebase generator functions, and verify end-to-end telemetry via `osm tune all --json` and empirical benchmarks via `osm perf all --quick`.

**Tech Stack:** Python 3.13 (`os_manager.commands.hsi`, `os_manager.commands.tune`), `systemd-zram-generator` 1.2+, `earlyoom`, Linux Kernel 6.12 (`zram`, `zstd`, `lru_gen`), `pytest`.

**Spec Reference:** `docs/superpowers/specs/2026-08-24-adaptive-kernel-system-optimization-design.md` (Section 3.1 & 4.2) and `docs/superpowers/specs/2026-08-22-hsi-device-security-hardening-design.md`.

## Global Constraints

- **INV-01 (Zero Data Loss):** Do not modify or format `/dev/nvme0n1p4` (`/mnt/data`).
- **INV-02 (Atomic State Snapshot):** Pre-apply backup of `/etc/systemd/zram-generator.conf` before writing new configuration.
- **INV-06 (Non-Interactive Sudo & Zero Hang):** All systemctl, swapoff, and swapon commands must execute non-interactively (`< /dev/null`, `sudo -S`).
- **RAM Safety Ceiling:** Maximum zRAM allocation capped at 100% of RAM (`min(ram, 8192)`).

```bash
# Ensure swap is active

# Refresh EarlyOOM daemon

```

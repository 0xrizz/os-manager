## 1. Environment & Global Guardrails
* **Target Environment:** Bare-Metal Debian GNU/Linux 13 (Trixie), Linux Kernel 6.12+, GNOME 48 (Wayland), Lenovo IdeaPad 3 (81WD) with Intel Core i5-1035G1 + NVIDIA GeForce MX330 + 8GB RAM + NVMe SSD.
* **Zero-Data-Loss on Persistent Storage:**
  * Partition 4 (Drive D: / `DATA_STORE` mounted at `/mnt/data`, NTFS `ntfs3`) contains permanent user data (~201 GB).
  * NEVER run destructive partition commands (`mkfs`, `fdisk d`, broad `rm -rf`, format) targeting Drive D: / `/dev/nvme0n1p4`.
* **Zero-USB Invariant:**
  * All system maintenance, kernel tuning, and partition operations must be 100% Zero-USB.
* **Non-Interactive Sudo Execution:**
  * When executing privileged commands, test `sudo -n true` or safely pipe password from `.env` using `sudo -S`.
* **Execution & Context Hygiene:**
  * Do not spin in polling loops. Rely on reactive wakeups. Keep subagent logs in report files.

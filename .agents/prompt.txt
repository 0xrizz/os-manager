## 1. Environment & Global Guardrails
* **Zero-Data-Loss on Persistent Storage:**
  * Partition 4 (Drive D: / `DATA_STORE`, NTFS) contains permanent user data.
  * NEVER run destructive partition commands (`mkfs`, `fdisk d`, broad `rm -rf`, format) targeting Drive D:.
* **Windows Interop Standard:**
  * When executing Windows binaries (`powershell.exe`, `cmd.exe`, `manage-bde.exe`), always append `< /dev/null` and use non-interactive flags (`-NoProfile -NonInteractive`).
* **Execution Hygiene:**
  * Do not spin in polling loops. Rely on reactive wakeups for asynchronous tasks.

  * Partition 4 (Drive D: / `DATA_STORE` mounted at `/mnt/data`, NTFS `ntfs3`) contains permanent user data (~201 GB).

  * When executing privileged commands, test `sudo -n true` or safely pipe password from `.env` using `sudo -S`.
